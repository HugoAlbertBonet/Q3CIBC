# ── The target ─────────────────────────────────────────────────────────────
# The number to beat is 91.3 (mean of 3 runs, sd 3.1): dpq3c's ImageNet
# checkpoints re-scored with the critic switched off, i.e. a plain diffusion
# policy on our recipe. Published q3c on this env is 86.7 (ImageNet, chunk 8)
# and 82.0 (scratch, chunk 16), both 3-seed means.
#
# So q3c is currently 4.6 points behind a diffusion policy here, and this batch
# asks whether that gap is real or whether q3c was simply never given the same
# treatment.
#
# ── What is being carried over from the dpq3c work ─────────────────────────
#   ImageNet trunk at 0.1x LR   +9.9 points for dpq3c on this env (p=0.0004),
#                               the single largest effect measured on libero.
#                               q3c trial 80 already used it, so this is a
#                               replication rather than a transfer.
#   300k steps                  Training length was the largest effect on
#                               pushing_pixels (+0.25). q3c on libero has only
#                               ever been run at 150k. Two lines test 300k.
#   3 seeds per configuration   Every conclusion we drew from single-seed cells
#                               had to be retracted later.
#
# Base recipe is q3c trial 80 (0.946 at n=500, the most trustworthy published
# q3c libero number): ImageNet resnet18 + GroupNorm + 128 keypoints, crop 116,
# frame_stack 1, chunk 16, 100 control points / top-k 30, cp 512x4, entropy
# separation at bandwidth 0.2, 8 Langevin negatives x 100 iterations, gradient
# penalty hinge 1.0/1.0. The film-fusion lines are trial 76's variant, which
# produced q3c's best single libero run.
#
# Read as 3-seed means against 91.3, never as best-of-N — q3c's headline numbers
# on both environments turned out to be best-of-many-trials artifacts, and that
# is exactly the comparison error this batch exists to avoid repeating.
