# ── One-at-a-time ablation from a FROZEN reference ─────────────────────────
# Reference = trial 36 (success 1.00, n=100), the best seed-averaged q3c configuration on this
# environment. Every line below changes exactly ONE parameter from it; nothing
# else moves. The first three lines are the reference itself at three seeds, so
# every sweep value has a like-for-like baseline measured under the same
# protocol rather than being compared against a published single run.
#
# 3 seeds per configuration, because single-seed cells have overturned several
# conclusions in this project already.
#
# ── inference_dfo_iterations is NOT swept here ─────────────────────────────
# It is an inference-time knob: it refines the control-point cloud a trained
# generator already produced, and changes nothing about training. Training a
# checkpoint per value would multiply this batch by five for no new weights.
# Instead every checkpoint from this batch gets re-scored at 0 / 3 / 5 / 10 / 20
# iterations afterwards, which is eval cost only. Generate that batch once these
# finish and you have pulled trials.jsonl back:
#
#   uv run python scripts/make_ablation_reeval.py --active-env pushing \
#       --extra pushing --out batches/ablPushingStatesEval.txt
#
# ── top_k clamping ─────────────────────────────────────────────────────────
# top_k_control_points selects from the cloud, so it cannot exceed it. On the
# control_points=1 and =5 cells it is clamped to 1 and 5 rather than left at the
# reference 8, which would have been silently invalid.
#
# ── "inference_uniform_proposal" ───────────────────────────────────────────
# No such key exists in SEARCH_SPACE, so it would have been silently dropped.
# The closest real knob is inference_dfo_num_uniform — the count of uniform
# safety samples mixed into the DFO population — and it is EVAL-ONLY. It is
# therefore handled in the re-scoring batch above, mapped as
# false -> 0 and true -> 8 (the value the pushing_pixels reference uses).
# Note it only does anything when inference_dfo_iterations > 0: with no DFO loop
# there is no population to add uniform samples to.
#
