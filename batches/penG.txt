# Batch penG - pen-human: RETRY Q3C + Langevin refinement with the FIXED chain.
# 8 trials via hyperparam_search.py --active-env pen. Results: d4rl/pen.
#
# Why retry: past pen inference-Langevin ran the OLD chain. Record
# (pen_inference_results.csv): aggressive lr = catastrophic (R 0 to -578);
# gentle lr = NEUTRAL (2515 ~ argmax 2575) at 35x argmax cost (74.5ms vs
# 2.1ms) - i.e. a near-no-op refinement, strictly dominated. The FIXED chain
# is a different object (noise annealing to zero via stepsize, full-cloud
# chains, post-refinement argmax re-scoring, optimize_again polish): on
# kitchen it BEAT argmax by +0.5 tasks (2.92 vs 2.43) where the old chain
# scored 0.17. penG tests whether that transfers to pen.
# Bar to beat: argmax 2575 (5-seed CSV) / 2522 (10-seed headline). If penG
# only matches it, conclusion = refinement pays where argmax has headroom
# (kitchen, SR 0%) and is unnecessary where argmax saturates (pen) - a clean
# per-env story either way.
#
# Base = B4 headline config (cp100/tk30, MLP Q 512x8 SN, lvneg8, 100k;
# 10-seed argmax = 2522 ~ paper IBC 2586, SR 67%). Upside: refinement rescuing
# borderline episodes -> beat the paper number + unify the inference recipe
# across envs. Q net untouched (faithfulness rule).
# Chain: full cloud, noise_via_stepsize, first-chain noise 1.0, again noise
# 0.5, delta_clip 0.5. lr bracketed low (pen 24-D; handoff found only gentle
# steps tolerable even on the broken path).
#
# Trials:
#   penG1-3: LV 30+20 lr0.1, seeds 0-2 (kitchen's winning schedule).
#   penG4  : LV 30+20 lr0.05.
#   penG5  : LV 30+20 lr0.02 (gentle, handoff-informed).
#   penG6  : LV 20+10 lr0.1 (cheaper schedule).
#   penG7  : LV 50+30 lr0.1 (longer, kitchen trend probe).
#   penG8  : EXPLORATORY resnet-Q (d4, no trailing ReLU) + LV 30+20 lr0.1 -
#            does the residual Q landscape refine better on pen too? (training
#            change - compare to penG1 not to B4.)
# Argmax control = existing B4 multiseed (2522 +/- 126, same config/codebase).
# Timing via bench_inference (same machine), not eval wall-clock.
