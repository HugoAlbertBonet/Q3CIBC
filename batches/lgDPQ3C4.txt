#     Diffusion Policy (scratch)    68.3   (paper, not in-house)

# The right comparator for the scratch/chunk16 lines here is 82.0. Against that,
# round 3 reads as a ~3 point gap, not the ~17 the single-run comparison

#     dpq3c ALIGN scratch chunk16   78.8   (mean of 5 runs, sd 3.0)
#     q3c   scratch chunk16         82.0   (mean of 3 seeds)

# per-env ranking is not stable across tasks and libero is the harder test.
#
# ── What round 3 established, and it stands ────────────────────────────────
#     CTRL   (dp_negatives 0)    mean 0.708   sd 0.036   5 runs
#     ALIGN  (dp_negatives 64)   mean 0.788   sd 0.030   5 runs
#     FULL   (+ margin+progress) mean 0.780   sd 0.099   7 runs
#     ALIGN vs CTRL   +0.080  z=+3.78  p<0.001  SIGNIFICANT
#     FULL  vs ALIGN  -0.008  z=-0.20  p=0.84   nothing
#
# Drawing the critic's negatives from the actor itself is worth +0.08 and is the
# one mechanism a separately-trained DP + Q3C pair cannot have. The optional
# terms leave the mean alone while TRIPLING the spread, so they are off in every
# line below.
#
# ── This batch (14 jobs) ───────────────────────────────────────────────────
# The first 8 are unchanged: the two pushing_pixels architecture wins (T=50 and
# denoiser_depth 2, both 0.97 there) ported to libero on the scratch trunk,
# individually and together.
#

# libero run so far has been from scratch, while q3c gains +4.7 points from

# against a scratch ALIGN mean of 0.788. One run is a hint, not a result; three
# seeds makes it a measurement. IMNET_s* is identical to the existing 5-run
# scratch ALIGN baseline except for the trunk, so the difference is attributable
# to pretraining alone.
#
# Read as MEANS with spread against ALIGN's 0.788. ~15-20 h per job at 200k
# steps, standard 50 eval episodes, never overridden.
