# ── READ THIS BEFORE INTERPRETING ANY NUMBER FROM THIS BATCH ───────────────
# IBC on this env is STRUCTURALLY HANDICAPPED relative to q3c and dpq3c, and no
# amount of hyperparameter sweeping inside this file can fix it.
# hyperparam_search_dfo.py does not expose two things the other two algorithms
# both use here:
#
#   ACTION CHUNKING   Absent entirely — there is no ACTION_CHUNK key in the dfo
#                     search space, and all 6 existing libero IBC trials ran
#                     unchunked. The q3c recipe that scores 82.0 on this env
#                     uses action_chunk 16, and chunking is the single largest
#                     known effect in this whole project.
#   ENCODER CHOICE    Hardcoded to conv_maxpool (hyperparam_search_dfo.py:472).
#                     q3c and dpq3c both use ResNet-18 + GroupNorm + 128
#                     SpatialSoftmax keypoints here.
#
# So the existing IBC best of 0.46 is a LOWER BOUND on what IBC can do on
# libero, not a measurement of IBC. Quoting it against q3c 82.0 or dpq3c 78.8
# without that caveat would misrepresent the algorithm — IBC scores 100.0 on
# pushing_pixels, where it is not handicapped this way.
#
# This batch does what CAN be done without touching the dfo trainer: tune the
# knobs it does expose, and get a replicate so the number has an error bar.
# Making the comparison genuinely fair needs ACTION_CHUNK and encoder support
# added to hyperparam_search_dfo.py first — a separate piece of work on a 67 KB
# script, worth doing before any cross-algorithm table is published.
#
# ── What the 6 existing trials suggest ─────────────────────────────────────
#     id1 0.30  id2 0.34  id3 0.40  id5 0.32 (crop 116)  id4 0.42 (neg 16)
#     id6 0.46  (INFERENCE_NUM_SAMPLES 512 -> 1024)
# The inference cloud size is the clearest lever: +0.06 from doubling it once.
# TRAINING_STEPS was never varied off 100k, while q3c and dpq3c use 150-200k on
# this env. Both are swept here.
#
# ── The sweep (10 jobs) ────────────────────────────────────────────────────
#   inference samples 1024 / 2048 / 4096
#   training steps    150k (default here) / 200k
#   counter-examples  8 / 16 / 32
#   image crop        0 / 116
#   3 seeds at the 2048 setting, plus a replicate of the existing best (trial 6)
#   so the 0.46 finally has a variance attached to it
#
# COST WARNING: IBC eval runs INFERENCE_NUM_SAMPLES x INFERENCE_NUM_ITERATIONS
# energy evaluations per action (2048 x 100 = 204800; 4096 x 100 = 409600).
# That is orders of magnitude above dpq3c's 10 denoiser passes plus one batched
# Q pass, and it is why the pushing_pixels comparison table records a
# scoring_evals column. The S4096 line is the one most likely to run long —
# drop it first if jobs hit the wall.
#
# Standard 50 eval episodes, inherited from the env config, never overridden.
