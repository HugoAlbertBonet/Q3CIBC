# LIBERO-Goal — explicit behaviour cloning (MSE regression), scratch and ImageNet.
#
# Submit with:  bash submit_experiments.sh batches/lgBC.txt
# Prereq:       uv sync --extra libero --extra pushing
#
# ── What runs ─────────────────────────────────────────────────────────────
# bc_mse_training.py — a standalone trainer, NOT combinedv2 with control_points=1.
# The earlier version of this batch used that reduction; it is arithmetically
# the same objective, but it still builds and trains a Q estimator, and a
# reviewer is entitled to object that the BC baseline is the proposed method
# wearing a flag. This trains a regression network and nothing else:
#
#     policy(obs) -> action          ONE forward pass, no control-point axis
#     loss = mean((policy(obs) - a_expert)^2)
#
# No control points, no energy function, no InfoNCE, no negatives, no critic —
# `utils.models.BCPolicy` has no critic submodule at all (asserted in the smoke
# test). At eval, hyperparam_search detects `bc_policy.pt`, builds BCPolicy,
# pairs it with the null critic, and forces control_points=1 with every
# refinement loop off, so the reported number is the regressed action itself.
#
# ── Matched to the q3c reference, so the objective is the only difference ──
# Encoder, conditioning, chunking, crop, schedule, optimiser and step count are
# copied from the ablLibero reference config: resnet18 / gn / 128 kp, FiLM goal
# conditioning, action_chunk 16, crop 116, cosine over 150k steps, lr 2e-4,
# batch 128, ema 0.999. bc_width/bc_depth = 512x4 matches cp_width/cp_depth
# there, so the regression trunk has the same capacity as the CP head it
# replaces. (bc_* are separate SEARCH_SPACE keys precisely so sweeping the BC
# baseline can never move the q3c generator.)
#
# ── Verified before writing this, not assumed ─────────────────────────────
# A 12-step run of bc_mse_training.py through its real path on a LIBERO-shaped
# dataset (this machine has no LIBERO data, so the loader was stubbed; the
# trainer, model, optimiser, EMA and checkpoint writer are the real ones):
#   13.29M params, "no critic, no control points"
#   MSE 0.339 -> 0.327 over 12 steps, no NaN
#   wrote bc_policy.pt, bc_policy_ema.pt, norm_stats.pt
#   the eval-side rebuild from norm_stats.pt strict-load()s that state_dict and
#   returns (1, 1, 112) = (B, N=1, action_dim 7 x chunk 16), in range
#   _NullCritic().score(...) -> (1, 1, 1), argmax 0 (picks the one action)
#   no submodule matching "critic"/"q_estimator" in the policy
#
# ── Reference points on this env (all n=50 eval episodes) ─────────────────
#   q3c film+scratch, N=1        94.0 +/- 3.2   (ablLibero, 5 runs)
#   q3c film+scratch, N=100      91.7 +/- 4.5   (ablLibero reference, 6 runs)
#   dpq3c ImageNet, cloud=1      91.3 +/- 3.1   (a diffusion policy, 3 runs)
#   IBC (resnet18, unchunked)    42.0 +/- 8.8
#
# The N=1 q3c row is what this is really testing. It is the best number on this
# environment, and the only thing between it and plain regression is the
# generator-InfoNCE term. If BC matches it, q3c at N=1 IS behaviour cloning and
# the paper should say so rather than let the reduction go unremarked.
#
# 3 seeds per encoder. Scratch is the ablLibero reference condition; ImageNet
# @ 0.1x LR is the setting worth +9.9 points to dpq3c on this env.
