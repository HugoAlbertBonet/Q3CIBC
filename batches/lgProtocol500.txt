# LIBERO-Goal — re-evaluate every method on the FULL protocol (500 episodes).
#
# Submit with:  bash submit_experiments.sh batches/lgProtocol500.txt
# Prereq:       uv sync --extra libero --extra pushing
#
# ── Why ───────────────────────────────────────────────────────────────────
# Our LIBERO numbers were all measured on 50 episodes: 10 tasks x 5 init states,
# always indices 0-4 of the 50 that LIBERO ships per task. Every method used the
# same subset, so the comparisons are internally consistent — but they are too
# coarse to resolve the differences we care about.
#
# Measured, not assumed. Seven q3c checkpoints have BOTH a 50-episode and a
# 500-episode score:
#
#     trial   50ep   500ep    diff
#        37   84.0    91.0    +7.0
#        62   88.0    92.0    +4.0
#        73   92.0    90.0    -2.0
#        74   80.0    94.6   +14.6
#        75   90.0    93.6    +3.6
#        76   96.0    93.0    -3.0
#        77   94.0    91.4    -2.6
#     mean diff +3.09, sd 6.38, paired t = +1.28 (not significant at n=7)
#
# So the 50-episode protocol is NOT biased — it is noisy, with a per-checkpoint
# error around +/- 6 points. That is larger than every gap in our table:
# BC-MSE 95.3 vs q3c N=1 94.0 vs dpq3c 91.3 are not distinguishable at that
# resolution, and one checkpoint moved 14.6 points between the two protocols.
# Any conclusion of the form "A beats B by 1-4 points on LIBERO" is currently
# unsupported.
#
# 500 episodes = 10 tasks x 50 init states = every init state LIBERO ships,
# which is also the widest protocol anyone runs on this suite.
#
# ── What is NOT being fixed here ──────────────────────────────────────────
# max_episode_steps stays at 300. LIBERO's own default is 600
# (third_party/LIBERO/libero/configs/eval/default.yaml), so our budget is half
# the standard one — that makes our numbers conservative, not inflated, and our
# successful episodes average 99-143 steps so it rarely binds. It is left alone
# because the 15 q3c 500-episode evals from July also used 300, and changing it
# would force those to be re-run too. It is now a SEARCH_SPACE key and an
# INFERENCE_ONLY_PARAM, so it can be set deliberately later instead of by
# editing config.json under running jobs.
#
# Also unfixed, and more important: even at 500 episodes these are a ~13M
# specialist trained on exactly the 10 tasks it is tested on. VLA numbers are
# large pretrained generalists. Matching the episode protocol does not make
# those rows comparable; it only makes OUR rows comparable to each other.
#
# ── Cost ──────────────────────────────────────────────────────────────────
# ~21.5 h per checkpoint at 500 episodes, measured from the July q3c runs
# (1304, 1287, 1327 min). Under the 48 h wall, and every line is independent.
# ONE CHECKPOINT PER LINE for that reason — batching 6 trials into a single
# reeval_trials.py call would need ~129 h and be killed.
#
# ── Already done, deliberately not repeated ───────────────────────────────
# q3c N=100 already has 15 checkpoints scored at 500 episodes (trials 65-72,
# 78-84 in the combinedv2 libero_goal_pixels trials.jsonl, range 82.4-94.6).
# Those stand as-is.
#
# ── 20 jobs ───────────────────────────────────────────────────────────────
