# ── One-at-a-time ablation from a FROZEN reference ─────────────────────────
# Reference = trial 95 (success 0.99, n=100), the best seed-averaged q3c configuration on this
# environment. Every line below changes exactly ONE parameter from it; nothing
# else moves. The first three lines are the reference itself at three seeds, so
# every sweep value has a like-for-like baseline measured under the same
# protocol rather than being compared against a published single run.
#
# 3 seeds per configuration, because single-seed cells have overturned several
# conclusions in this project already.
#
# ── inference_dfo_iterations is NOT swept here ─────────────────────────────
# It is an inference-time knob: it refines the control-point cloud a trained
# generator already produced, and changes nothing about training. Training a
# checkpoint per value would multiply this batch by five for no new weights.
# Instead every checkpoint from this batch gets re-scored at 0 / 3 / 5 / 10 / 20
# iterations afterwards, which is eval cost only. Generate that batch once these
# finish and you have pulled trials.jsonl back:
#
#   uv run python scripts/make_ablation_reeval.py --active-env pushing_pixels \
#       --extra pushing --out batches/ablPushingPixelsEval.txt
#
# ── top_k clamping ─────────────────────────────────────────────────────────
# On the control_points=1 cell top_k_control_points is clamped to 1 rather than
# left at the reference 8, which would have been silently invalid.
#
