# Consistency Policy — flat-state environments (particle 2D/16D, pen, kitchen, pushing states).
#
# Submit with:  bash submit_experiments.sh batches/cpFlat.txt
#
# ── Algorithm: Consistency Policy (Prasad et al., 2024 — arXiv 2405.07503) ──
# consistency_policy_training.py + utils/consistency.py, ported from the official
# repo (configs edm_*/ctmp_*.yaml): EDM teacher (sigma 0.02-80, rho 7, 80 bins,
# sigma_data 0.5, boundary preconditioning, log-normal sigma, Karras-weighted
# pseudo-Huber with delta = 0.00054*sqrt(action dims)), then a CTM student
# warm-started from it (zero-initialised stop-time input, frozen image encoder,
# dropout 0.2, loss ctm + dsm with weights 1/1, one teacher Heun step u = t+1,
# target net = student copy every step). AdamW betas (0.95, 0.999) wd 1e-6,
# cosine LR with 500 warmup steps (student schedule over 80% of its steps),
# teacher evaluated with its power-schedule EMA, student with raw weights, and
# the student trains 1.25x the teacher's steps (official 500 vs 400 epochs).
#
# Trunk, batch size, learning rate and teacher step count are our best Diffusion
# Policy recipe for each env, so CP and DP differ only in the algorithm.
# hyperparam_search detects cp_meta.json and scores the checkpoint like plain DP:
# null critic, control_points=1, no refinement. The student samples ONE network
# evaluation per action: z ~ N(0, I) -> G(z, 80, 0.02). All runs carry
# cp_run_tag=cpv1, which cpReeval.txt uses to find them.
#
# cp_phase=both: teacher then student in the same run; the trial record scores the
# student (1 step). Recipes (source batch):
#   particle 2D/16D  dense_resnet 1024x1  bs512 lr3e-4  300k teacher / 375k student  (dpParticleV2 / dpParticle)
#   pen              mlp 512x8            bs512 lr5e-4  100k / 125k                   (penDPA)
#   kitchen (qpos)   resnet 512x4         bs512 lr5e-4  150k / 187.5k                 (kitchenDPC)
#   pushing states   resnet 128x4         bs512 lr1e-3  200k / 250k                   (pushingDPB)
#
# Cost (RTX 5070 laptop, synthetic batches): teacher step 0.9-1.4x a DP step,
# student step 3.5-5.3x (five small-network passes), <= 13 ms. DP on these envs
# took 0.2-0.5 h per run on the cluster, so each CP run is ~1-2 h expected.
#
# 15 runs -> 5 jobs (one per env, seeds 0-2 packed; ~3-6 h expected per job).
