# LIBERO-Goal pixels — THIRD-PERSON CAMERA ONLY, every method, full protocol.
#
# Submit with:  bash submit_experiments.sh batches/lgThirdPerson.txt
# Prereq:       uv sync --extra libero --extra pushing
#
# ── Why ───────────────────────────────────────────────────────────────────
# The published LIBERO numbers for Octo (84.6 Goal), Diffusion Policy from
# scratch (68.3) and OpenVLA (79.2) come from the OpenVLA paper, Appendix E.1:
# "For all methods in our comparisons, we only utilize the static third-person
# camera images; we do not use the wrist camera images." Each policy was trained
# on one suite's 10 tasks only — the same task set as ours. ProgressVLA (87.2)
# fine-tunes on that same OpenVLA data. Our specialists were trained with BOTH
# cameras, i.e. with more input than those rows. This batch removes the wrist
# camera so those comparisons are like-for-like on camera input.
#
# ── What changes, and what does not ───────────────────────────────────────
# ONLY `libero_cameras: "agentview"` (new, default "agentview+wrist"). Every
# other key is copied from the reference trial's record. Still different from
# the OpenVLA protocol, deliberately not changed here:
#   * proprioception is still an input (OpenVLA's rows used image + language)
#   * original LIBERO demos at 128x128 (theirs: re-rendered at 256, no-op
#     actions and 72/500 failed Goal demos removed, images rotated 180 deg)
#   * no robot pretraining (Octo / OpenVLA / ProgressVLA are pretrained)
#
# ── Evaluation ────────────────────────────────────────────────────────────
# num_eval_seeds 500 = 10 tasks x init states 0-49, max 300 steps, 10 settle
# steps: the OpenVLA LIBERO-Goal evaluation. Each job trains AND evaluates, so
# no reeval batch is needed. Longest: dpq3c ~19.5 h (under the 48 h wall).
# The trainer records the camera set in norm_stats, and the eval sim reads it
# back from the checkpoint, so any later reeval uses the same single camera.
#
# ── References (both cameras, 500 episodes) ───────────────────────────────
#   BC-MSE ImageNet 95.8 +/- 0.7 | BC-MSE scratch 94.1 +/- 1.9
#   q3c N=1 93.9 +/- 0.7 | dpq3c cloud=1 90.5 +/- 1.0 | IBC: re-run pending
#   (lgProtocol500IBCfix). Published, third-person only: OpenVLA 79.2,
#   Octo 84.6, Diffusion Policy 68.3, ProgressVLA 87.2.
#
# 15 jobs: 5 methods x 3 seeds. IBC runs all 3 seeds with cond_fusion "concat"
# (its reference seeds mixed concat and film).
