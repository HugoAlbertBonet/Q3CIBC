# ── Reference ─────────────────────────────────────────────────────────────
# The best pen q3c config on record: 71.3 +/- 4.2 argmax over 9 seeds
# (batches/penChunkA.txt: 100 CPs / top_k 30, 512x8 generator and critic, lr 5e-4,
# 100k steps, action_chunk 4, 8 Langevin negatives x 100 iters, argmax eval).
# Every key is pinned from trial 110's recorded params where the record has it,
# else from the resolved config; new knobs sit at their old-behaviour values.

# ── Why these axes ────────────────────────────────────────────────────────
# On particle-16D, argmax went 0% -> 82.7% by (a) a linear CP head instead of
# tanh, (b) removing a Lipschitz cap on the critic (GP margin 1), and (c) near-CP
# InfoNCE positives. Pen is different in ways that matter:
#  * EVERY earlier pen run trained with GP 1.0 hinge, whatever its batch asked:
#    the GP override was silently shadowed until 2425854a. GP-off is untested.
#  * Pen's critic also has SPECTRAL NORM (q_use_spectral_norm true), which is a
#    Lipschitz cap as well, so GP off alone may not free it -> F7, F8, C1, C2.
#  * Pen already scores with argmax (Langevin-100 averages 20.9%), so turning
#    GP off cannot break its inference mode the way it breaks Langevin.
#  * Actions are normalised per dim to [-1, 1] and chunked x4 (96-dim), and the
#    pen sim clips after de-normalising, so a linear head is safe here. The
#    positive radius is in that 96-dim space: 0.25 is roughly particle's 0.05
#    rescaled for box width and dimension.
#
# ── Arms (3 seeds each, argmax, pen's standard 100 eval episodes) ─────────
#   F1-F4  2x2 core: head {tanh, linear} x GP {on (1.0 hinge m1), off}
#   F5-F6  GP kept but margin 10, both heads
#   F7-F8  GP off AND critic spectral norm off, both heads
#   A1-A9  one-at-a-time from F4 (linear + GP off)
#   C1-C2  combinations
# 19 arms x 3 seeds = 57 jobs. Pen jobs on this reference ran ~16-18 h each
# (under the 48 h wall); A8 drops the Langevin negatives and should be much faster.
